What it is

A mod is the change. The plugin is the package that brings it to Claude Code.

The Claude Mods Starter Kit is a community project by Prompt Advisers (MIT license), mirrored here at INEMA. It includes ten real plugins, a marketplace to install them, test scripts and a fictional demo project so you can experiment without touching your own work.

🧩 Ten working mods

Source code, manifests and tests for every plugin. 124 unit tests passing on version 1.0.0 (Claude Code 2.1.287).

📝 Ten complete prompts

In the prompts/ folder, one specification per mod: behavior, controls, failure cases and acceptance criteria. Paste it into Claude Code and it builds the mod.

🧪 Try it with no commitment

scripts/try.sh creates a temporary folder with the demo project and opens Claude Code with only the mod you chose. Your settings do not change.

How it works

Event → mod → result on screen

Claude Code signals that something happened (it read a file, finished a tool, measured the context, redrew the screen). The mod's code handles that event and changes what you see or how the work flows. The pet does not need a new AI answer for every frame: it is code reacting to events.

Something happens→ Claude Code sends an event→ The mod handles the event→ A panel, counter or file changes→ Work carries on as usual

Some mods only draw information. Others write files (Auto Handoff, Bookmarks) or change which model runs (Model Router). Each mod's guide says which is which.

The 10 mods

Pick the change you want

Each mod has its own guide in guides/ with installation, controls, a demo prompt, how to turn it off and its limits. The commands below are typed inside Claude Code, one at a time.

🦀 Terminal Pet

A pixel-art crab above the prompt that reacts when Claude reads, writes, waits, finishes or fails.

/pet on   /pet party   /pet name Pixel   /pet off

🎨 Coral Skin

A coral, ink and cream theme for messages and tools, with colors by action type (read, edit, command).

/skin on   /skin risk   /skin off

⛽ Context Meter

Shows how full the conversation is, the session cost and the usage limits available, above the prompt.

# automatic, no command

🗺️ Repo Heatmap

A map of the project's files that lights up as Claude reads, searches and edits.

/heatmap open   /heatmap size lines   /heatmap reset   /heatmap close

📈 Flight Recorder

A timeline (Gantt) of turns, tool calls and subagents, with tokens and estimated cost per bar.

/timeline open   /timeline turns 5   /timeline clear   /timeline close

🔀 Model Router

Sends subagent work to Sonnet (or Haiku) while the main conversation stays on its own model.

/router on   /router mode subagents   /router sonnet   /router off

🗂️ Output Tray

A panel with the files created in the session: copy the path, open, and reveal in Finder (open/reveal on macOS only).

/tray show   /tray list   /tray copy 1   /tray close

🧾 Changes Receipt

A receipt of what was created, edited and deleted in a turn, separating what worked from the attempts that failed.

/receipt on   /receipt last   /receipt open   /receipt off

🔖 Session Bookmarks

Saves a title and a note together with the project and session, so you can find the conversation again and resume it.

/bm save Login walkthrough   /bm list   /bm find login   /bm resume 1

🤝 Auto Handoff

Writes a summary of progress, decisions and next steps to the project (default: at 85% of context) so the next conversation can pick up where this one left off.

/autohandoff now   /autohandoff threshold 85   /autohandoff resume   /autohandoff off
Prerequisites

What needs to be installed

These are mods for Claude Code (the CLI or the Code area of the desktop app), not for the regular Claude chat or a browser extension. The scripts use Bash and Python 3. On Windows, use WSL.

Claude Code, logged in

With plugin support and a compatible plan or API account.

claude --version

Git

Required to install from the marketplace.

git --version

Python 3 + Bash

For the try.sh, manage.sh and check.sh scripts.

python3 --version
User guide · step by step

From your first pet to the full kit

Start with Terminal Pet, which only draws on the screen. Then add whatever makes sense for you. Router and Handoff change behavior, so choose those carefully.

1

Download the kit

Clone the repository. To read everything without installing anything, open VIEWER-GUIDE.html in your browser or the PDF CLAUDE-MODS-VIEWER-GUIDE.pdf.

git clone https://github.com/inematds/claude-mods-starter-kit
cd claude-mods-starter-kit
2

Try a mod without installing it

The script copies the demo project into a fresh temporary folder and opens Claude Code there, with only the requested mod. Your plugin settings do not change.

bash scripts/try.sh terminal-pet
# inside Claude Code:
/pet party   # the pet celebrates
/pet off     # hides it
/exit        # leaves the temporary session
3

Install for all your projects

Add the marketplace (the original from Prompt Advisers, or the mirror inematds/claude-mods-starter-kit) and install the mod. Then open a new Claude Code session.

claude plugin marketplace add promptadvisers/claude-mods-starter-kit --scope user
claude plugin install terminal-pet@claude-mods-kit --scope user
4

Or in just one project

Run it in the project folder. --scope project writes to the project configuration (it can go into your teammates' git); --scope local stays just for you. Pick one scope, not all of them.

claude plugin marketplace add promptadvisers/claude-mods-starter-kit --scope project
claude plugin install terminal-pet@claude-mods-kit --scope project
5

Install several (or all ten)

From the root of the downloaded kit, after adding the marketplace. all installs all ten, including Router and Handoff. Open one side panel at a time.

bash scripts/manage.sh install user all
bash scripts/manage.sh install user repo-heatmap
6

Try it in the demo project

demo-project/ is a fictional store with a login flow. Open the heatmap and ask for an investigation: the files light up while Claude works.

/heatmap open
Investigate the login flow, from src/ui/LoginForm.tsx to src/auth/login.ts,
session.ts and tokens.ts. Read the files and explain how the user signs in. Do not edit anything.
7

Turn it off whenever you want

This disables only this kit's plugins in the given scope. For a single mod, use claude plugin disable. Close old sessions afterwards.

bash scripts/manage.sh disable user all
claude plugin disable terminal-pet@claude-mods-kit --scope user
Build your own

From an idea in plain language to a tested mod

Tell Claude five things: which event to watch, what result to show, where it appears, how to turn it off and how to test it. "Make it look nice" does not define reliable behavior.

1

Use a ready-made prompt

Open a file in prompts/, copy the whole specification and ask Claude Code to build it in a new folder. Adjust colors and style.

2

Start from the minimal template

templates/starter-mod counts successful reads and shows the number. Rename the manifest, state and command before turning it into another plugin.

3

Validate before sharing

Test in a disposable folder with --plugin-dir, ask for a failure test and an off switch. Remove settings, transcripts and personal paths.

# typical plugin structure
my-plugin/
  .claude-plugin/plugin.json   # name and version
  hooks/hooks.json             # which module to load
  hooks/starter.mjs            # handles the events
  tests/starter.test.ts        # behavior tests

# validates the whole kit
bash scripts/check.sh
Honest limits

What the kit does not promise

Version 1.0.0, checked with Claude Code 2.1.287 on macOS on October 2, 2026. Host APIs and model availability may change.

Tests
124 unit tests, no end-to-end certificationThe tests simulate the terminal and desktop. There was no live desktop session with all ten mods, and no live test on Windows or Linux.
Cost
Amounts are estimatesThe dollar figures in Context Meter and Flight Recorder are API equivalents, not charges on your subscription.
Router
Changes which model does the workA subagent on a cheaper model may answer differently. A model missing from the price table is not routed. Review the result.
Handoff
Writes files and makes one extra model callThe summary may miss details. The files stay in the project after you turn it off: review them before sharing.
Tray
Open/Reveal on macOS onlyThe list works on any system, but the Open and Reveal buttons use Finder.
Visual
Color and mood are decorationCoral Skin's risk colors and the nervous crab do not block any dangerous action.
