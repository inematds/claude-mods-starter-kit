Qué es

Un mod es el cambio. El plugin es el paquete que lo lleva a Claude Code.

El Claude Mods Starter Kit es un proyecto comunitario de Prompt Advisers (licencia MIT), reflejado aquí en INEMA. Trae diez plugins de verdad, un marketplace para instalarlos, scripts de prueba y un proyecto de demostración ficticio para que experimentes sin tocar tu trabajo.

🧩 Diez mods funcionando

Código fuente, manifiestos y pruebas de cada plugin. 124 pruebas unitarias pasando en la versión 1.0.0 (Claude Code 2.1.287).

📝 Diez prompts completos

En la carpeta prompts/, una especificación por mod: comportamiento, controles, casos de falla y criterios de aceptación. Pégala en Claude Code y él lo construye.

🧪 Prueba sin compromiso

scripts/try.sh crea una carpeta temporal con el proyecto de demostración y abre Claude Code solo con el mod elegido. Tu configuración no cambia.

Cómo funciona

Evento → mod → resultado en pantalla

Claude Code avisa que algo ocurrió (leyó un archivo, terminó una herramienta, midió el contexto, dibujó la pantalla). El código del mod maneja ese evento y cambia lo que ves o el flujo de trabajo. La mascota no necesita una respuesta nueva de la IA en cada cuadro: es código que reacciona a eventos.

Algo ocurre→ Claude Code envía un evento→ El mod maneja el evento→ Cambia un panel, un contador o un archivo→ El trabajo sigue normal

Algunos mods solo dibujan información. Otros escriben archivos (Auto Handoff, Bookmarks) o cambian qué modelo se ejecuta (Model Router). La guía de cada uno dice cuál es cuál.

Los 10 mods

Elige el cambio que quieres

Cada mod tiene su propia guía en guides/ (en inglés) con instalación, controles, prompt de demostración, cómo apagarlo y límites. Los comandos de abajo se escriben dentro de Claude Code, uno a la vez.

🦀 Terminal Pet

Un cangrejo pixel-art sobre el prompt que reacciona cuando Claude lee, escribe, espera, termina o falla.

/pet on   /pet party   /pet name Pixel   /pet off

🎨 Coral Skin

Tema coral, tinta y crema en los mensajes y herramientas, con colores según el tipo de acción (lectura, edición, comando).

/skin on   /skin risk   /skin off

⛽ Context Meter

Muestra qué tan llena está la conversación, el costo de la sesión y los límites de uso disponibles, sobre el prompt.

# automático, sin comando

🗺️ Repo Heatmap

Mapa de los archivos del proyecto que se enciende a medida que Claude lee, busca y edita.

/heatmap open   /heatmap size lines   /heatmap reset   /heatmap close

📈 Flight Recorder

Línea de tiempo (Gantt) de los turnos, llamadas a herramientas y subagentes, con tokens y costo estimado por tramo.

/timeline open   /timeline turns 5   /timeline clear   /timeline close

🔀 Model Router

Envía el trabajo de los subagentes a Sonnet (o Haiku) mientras la conversación principal sigue en su modelo.

/router on   /router mode subagents   /router sonnet   /router off

🗂️ Output Tray

Panel con los archivos creados en la sesión: copiar la ruta, abrir y mostrar en el Finder (abrir/mostrar solo en macOS).

/tray show   /tray list   /tray copy 1   /tray close

🧾 Changes Receipt

Recibo de lo que se creó, editó y borró en un turno, separando lo que salió bien de los intentos que fallaron.

/receipt on   /receipt last   /receipt open   /receipt off

🔖 Session Bookmarks

Guarda un título y una nota junto con el proyecto y la sesión, para que encuentres la conversación de nuevo y la retomes.

/bm save Login walkthrough   /bm list   /bm find login   /bm resume 1

🤝 Auto Handoff

Guarda en el proyecto un resumen del progreso, las decisiones y los próximos pasos (por defecto: al llegar al 85% del contexto) para que la próxima conversación continúe.

/autohandoff now   /autohandoff threshold 85   /autohandoff resume   /autohandoff off
Requisitos previos

Qué debe estar instalado

Son mods para Claude Code (CLI o área Code de la app de escritorio), no para el chat común de Claude ni una extensión de navegador. Los scripts usan Bash y Python 3. En Windows, usa WSL.

Claude Code con sesión iniciada

Con soporte para plugins y un plan o cuenta de API compatible.

claude --version

Git

Necesario para instalar desde el marketplace.

git --version

Python 3 + Bash

Para los scripts try.sh, manage.sh y check.sh.

python3 --version
Guía de uso · paso a paso

De la primera mascota al kit completo

Empieza por Terminal Pet, que solo dibuja en pantalla. Después agrega lo que tenga sentido. Router y Handoff cambian el comportamiento: elígelos con calma.

1

Descarga el kit

Clona el repositorio. Para leer todo sin instalar nada, abre el VIEWER-GUIDE.html en el navegador o el PDF CLAUDE-MODS-VIEWER-GUIDE.pdf.

git clone https://github.com/inematds/claude-mods-starter-kit
cd claude-mods-starter-kit
2

Prueba un mod sin instalar

El script copia el proyecto de demostración a una carpeta temporal nueva y abre Claude Code allí, solo con el mod pedido. Tu configuración de plugins no cambia.

bash scripts/try.sh terminal-pet
# dentro de Claude Code:
/pet party   # la mascota celebra
/pet off     # la oculta
/exit        # sale de la sesión temporal
3

Instálalo para todos tus proyectos

Agrega el marketplace (el original de Prompt Advisers, o el espejo inematds/claude-mods-starter-kit) e instala el mod. Después abre una sesión nueva de Claude Code.

claude plugin marketplace add promptadvisers/claude-mods-starter-kit --scope user
claude plugin install terminal-pet@claude-mods-kit --scope user
4

O solo en un proyecto

Ejecútalo en la carpeta del proyecto. --scope project guarda en la configuración del proyecto (puede ir al git de tus compañeros); --scope local queda solo para ti. Elige un alcance, no todos.

claude plugin marketplace add promptadvisers/claude-mods-starter-kit --scope project
claude plugin install terminal-pet@claude-mods-kit --scope project
5

Instala varios (o los diez)

Desde la raíz del kit descargado, después de agregar el marketplace. all instala los diez, incluidos Router y Handoff. Abre un panel lateral a la vez.

bash scripts/manage.sh install user all
bash scripts/manage.sh install user repo-heatmap
6

Pruébalo en el proyecto de demostración

El demo-project/ es una tienda ficticia con flujo de inicio de sesión. Abre el heatmap y pide una investigación: los archivos se encienden mientras Claude trabaja.

/heatmap open
Investiga el flujo de inicio de sesión, desde src/ui/LoginForm.tsx hasta src/auth/login.ts,
session.ts y tokens.ts. Lee los archivos y explica cómo entra el usuario. No edites nada.
7

Apágalo cuando quieras

Desactiva solo los plugins de este kit en el alcance indicado. Para un solo mod, usa claude plugin disable. Cierra las sesiones antiguas después.

bash scripts/manage.sh disable user all
claude plugin disable terminal-pet@claude-mods-kit --scope user
Crea el tuyo

De una idea en español a un mod probado

Dile a Claude cinco cosas: qué evento observar, qué resultado mostrar, dónde aparece, cómo apagarlo y cómo probarlo. "Hazlo bonito" no define un comportamiento confiable.

1

Usa un prompt listo

Abre un archivo de prompts/, copia la especificación completa y pídele a Claude Code que la construya en una carpeta nueva. Ajusta colores y estilo.

2

Parte del modelo mínimo

templates/starter-mod cuenta las lecturas exitosas y muestra el número. Renombra manifiesto, estado y comando antes de convertirlo en otro plugin.

3

Valida antes de compartir

Prueba en una carpeta desechable con --plugin-dir, pide una prueba de falla y un botón para apagar. Quita configuraciones, transcripciones y rutas personales.

# estructura típica de un plugin
my-plugin/
  .claude-plugin/plugin.json   # nombre y versión
  hooks/hooks.json             # qué módulo cargar
  hooks/starter.mjs            # quien maneja los eventos
  tests/starter.test.ts        # pruebas de comportamiento

# valida el kit completo
bash scripts/check.sh
Límites honestos

Lo que el kit no promete

Versión 1.0.0, verificada con Claude Code 2.1.287 en macOS el 2 de octubre de 2026. Las APIs del host y la disponibilidad de modelos pueden cambiar.

Pruebas
124 pruebas unitarias, sin certificación de extremo a extremoLas pruebas simulan terminal y escritorio. No hubo sesión de escritorio en vivo con los diez mods, ni prueba en vivo en Windows o Linux.
Costo
Los valores son estimacionesLos dólares de Context Meter y Flight Recorder son equivalentes de API, no un cobro de tu suscripción.
Router
Cambia qué modelo trabajaUn subagente en un modelo más barato puede responder distinto. Un modelo desconocido en la tabla de precios no se enruta. Revisa el resultado.
Handoff
Escribe archivos y hace una llamada extra al modeloEl resumen puede perder detalles. Los archivos quedan en el proyecto después de apagarlo: revísalos antes de compartir.
Tray
Abrir/Mostrar solo en macOSLa lista funciona en cualquier sistema, pero los botones Open y Reveal usan el Finder.
Visual
El color y el humor son decoraciónLos colores de riesgo de Coral Skin y el cangrejo nervioso no bloquean ninguna acción peligrosa.
