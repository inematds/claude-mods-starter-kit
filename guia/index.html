O que é

Um mod é a mudança. O plugin é o pacote que leva ela pro Claude Code.

O Claude Mods Starter Kit é um projeto comunitário da Prompt Advisers (licença MIT), espelhado aqui no INEMA. Ele traz dez plugins de verdade, um marketplace para instalar, scripts de teste e um projeto de demonstração fictício para você experimentar sem mexer no seu trabalho.

🧩 Dez mods funcionando

Código-fonte, manifestos e testes de cada plugin. 124 testes unitários passando na versão 1.0.0 (Claude Code 2.1.287).

📝 Dez prompts completos

Na pasta prompts/, uma especificação por mod: comportamento, controles, casos de falha e critérios de aceite. Cole no Claude Code e ele constrói.

🧪 Teste sem compromisso

scripts/try.sh cria uma pasta temporária com o projeto de demonstração e abre o Claude Code só com o mod escolhido. Suas configurações não mudam.

Como funciona

Evento → mod → resultado na tela

O Claude Code avisa que algo aconteceu (leu um arquivo, terminou uma ferramenta, mediu o contexto, desenhou a tela). O código do mod trata esse evento e muda o que você vê ou o fluxo de trabalho. O bichinho não precisa de uma resposta nova da IA a cada quadro: é código reagindo a eventos.

Algo acontece→ Claude Code envia um evento→ O mod trata o evento→ Painel, contador ou arquivo muda→ O trabalho segue normal

Alguns mods só desenham informação. Outros gravam arquivos (Auto Handoff, Bookmarks) ou mudam qual modelo roda (Model Router). O guia de cada um diz qual é qual.

Os 10 mods

Escolha a mudança que você quer

Cada mod tem um guia próprio em guides/ (em inglês) com instalação, controles, prompt de demonstração, como desligar e limites. Os comandos abaixo são digitados dentro do Claude Code, um de cada vez.

🦀 Terminal Pet

Um caranguejo pixel-art acima do prompt que reage quando o Claude lê, escreve, espera, termina ou erra.

/pet on   /pet party   /pet name Pixel   /pet off

🎨 Coral Skin

Tema coral, tinta e creme nas mensagens e ferramentas, com cores por tipo de ação (leitura, edição, comando).

/skin on   /skin risk   /skin off

⛽ Context Meter

Mostra quanto a conversa está cheia, o custo da sessão e os limites de uso disponíveis, acima do prompt.

# automático, sem comando

🗺️ Repo Heatmap

Mapa dos arquivos do projeto que acende conforme o Claude lê, busca e edita.

/heatmap open   /heatmap size lines   /heatmap reset   /heatmap close

📈 Flight Recorder

Linha do tempo (Gantt) dos turnos, chamadas de ferramenta e subagentes, com tokens e custo estimado por faixa.

/timeline open   /timeline turns 5   /timeline clear   /timeline close

🔀 Model Router

Manda o trabalho dos subagentes para Sonnet (ou Haiku) enquanto a conversa principal segue no modelo dela.

/router on   /router mode subagents   /router sonnet   /router off

🗂️ Output Tray

Painel com os arquivos criados na sessão: copiar caminho, abrir e mostrar no Finder (abrir/mostrar só no macOS).

/tray show   /tray list   /tray copy 1   /tray close

🧾 Changes Receipt

Recibo do que foi criado, editado e apagado num turno, separando o que deu certo das tentativas que falharam.

/receipt on   /receipt last   /receipt open   /receipt off

🔖 Session Bookmarks

Salva título e nota com o projeto e a sessão, pra você achar a conversa de novo e retomar.

/bm save Login walkthrough   /bm list   /bm find login   /bm resume 1

🤝 Auto Handoff

Grava no projeto um resumo do progresso, decisões e próximos passos (padrão: ao chegar em 85% do contexto) para a próxima conversa continuar.

/autohandoff now   /autohandoff threshold 85   /autohandoff resume   /autohandoff off
Pré-requisitos

O que precisa estar instalado

São mods para o Claude Code (CLI ou área Code do app desktop), não para o chat comum do Claude nem extensão de navegador. Os scripts usam Bash e Python 3. No Windows, use WSL.

Claude Code logado

Com suporte a plugins e um plano ou conta de API compatível.

claude --version

Git

Necessário para instalar pelo marketplace.

git --version

Python 3 + Bash

Para os scripts try.sh, manage.sh e check.sh.

python3 --version
Guia de uso · passo a passo

Do primeiro bichinho ao kit completo

Comece pelo Terminal Pet, que só desenha na tela. Depois acrescente o que fizer sentido. Router e Handoff mudam o comportamento: escolha esses com calma.

1

Baixe o kit

Clone o repositório. Para ler tudo sem instalar nada, abra o VIEWER-GUIDE.html no navegador ou o PDF CLAUDE-MODS-VIEWER-GUIDE.pdf.

git clone https://github.com/inematds/claude-mods-starter-kit
cd claude-mods-starter-kit
2

Teste um mod sem instalar

O script copia o projeto de demonstração para uma pasta temporária nova e abre o Claude Code ali, só com o mod pedido. Suas configurações de plugin não mudam.

bash scripts/try.sh terminal-pet
# dentro do Claude Code:
/pet party   # o bichinho comemora
/pet off     # esconde
/exit        # sai da sessão temporária
3

Instale para todos os seus projetos

Adicione o marketplace (o original da Prompt Advisers, ou o espelho inematds/claude-mods-starter-kit) e instale o mod. Depois abra uma sessão nova do Claude Code.

claude plugin marketplace add promptadvisers/claude-mods-starter-kit --scope user
claude plugin install terminal-pet@claude-mods-kit --scope user
4

Ou só num projeto

Rode na pasta do projeto. --scope project grava na configuração do projeto (pode ir pro git dos colegas); --scope local fica só pra você. Escolha um escopo, não todos.

claude plugin marketplace add promptadvisers/claude-mods-starter-kit --scope project
claude plugin install terminal-pet@claude-mods-kit --scope project
5

Instale vários (ou os dez)

Da raiz do kit baixado, depois de adicionar o marketplace. all instala os dez, inclusive Router e Handoff. Abra um painel lateral de cada vez.

bash scripts/manage.sh install user all
bash scripts/manage.sh install user repo-heatmap
6

Experimente no projeto de demonstração

O demo-project/ é uma loja fictícia com fluxo de login. Abra o heatmap e peça uma investigação: os arquivos acendem enquanto o Claude trabalha.

/heatmap open
Investigue o fluxo de login, de src/ui/LoginForm.tsx até src/auth/login.ts,
session.ts e tokens.ts. Leia os arquivos e explique como o usuário entra. Não edite nada.
7

Desligue quando quiser

Desativa só os plugins deste kit no escopo indicado. Para um mod só, use o claude plugin disable. Feche as sessões antigas depois.

bash scripts/manage.sh disable user all
claude plugin disable terminal-pet@claude-mods-kit --scope user
Criar o seu

De uma ideia em português a um mod testado

Diga ao Claude cinco coisas: qual evento observar, que resultado mostrar, onde aparece, como desligar e como testar. "Deixa bonito" não define um comportamento confiável.

1

Use um prompt pronto

Abra um arquivo de prompts/, copie a especificação inteira e peça ao Claude Code para construir numa pasta nova. Ajuste cores e estilo.

2

Parta do modelo mínimo

templates/starter-mod conta leituras bem-sucedidas e mostra o número. Renomeie manifesto, estado e comando antes de virar outro plugin.

3

Valide antes de compartilhar

Teste numa pasta descartável com --plugin-dir, peça um teste de falha e um botão de desligar. Tire configurações, transcrições e caminhos pessoais.

# estrutura típica de um plugin
my-plugin/
  .claude-plugin/plugin.json   # nome e versão
  hooks/hooks.json             # qual módulo carregar
  hooks/starter.mjs            # quem trata os eventos
  tests/starter.test.ts        # testes de comportamento

# valida o kit inteiro
bash scripts/check.sh
Limites honestos

O que o kit não promete

Versão 1.0.0, conferida com Claude Code 2.1.287 no macOS em 2 de outubro de 2026. APIs do host e disponibilidade de modelos podem mudar.

Testes
124 testes unitários, sem certificação de ponta a pontaOs testes simulam terminal e desktop. Não houve sessão desktop ao vivo com os dez mods, nem teste ao vivo em Windows ou Linux.
Custo
Valores são estimativasOs dólares do Context Meter e do Flight Recorder são equivalentes de API, não cobrança da sua assinatura.
Router
Muda qual modelo trabalhaUm subagente num modelo mais barato pode responder diferente. Modelo desconhecido na tabela de preços não é roteado. Revise o resultado.
Handoff
Grava arquivos e faz uma chamada extra ao modeloO resumo pode perder detalhes. Os arquivos ficam no projeto depois de desligar: revise antes de compartilhar.
Tray
Abrir/Mostrar só no macOSA lista funciona em qualquer sistema, mas os botões Open e Reveal usam o Finder.
Visual
Cor e humor são decoraçãoAs cores de risco do Coral Skin e o caranguejo nervoso não bloqueiam nenhuma ação perigosa.
